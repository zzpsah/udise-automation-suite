# UDISE Automation Suite

Private Google Colab notebook for authenticated UDISE+ school workflows.

## Included workflows

- Authentication and school detection
- Current academic-session student roster export
- General Profile export, validation, and guarded updates
- Class IX/X Enrollment Profile subject-rule loading
- Enrollment Excel export and validation
- Guarded Enrollment submission with one-record default and server read-back verification

## Important

Keep this repository private. Do not commit session cookies, credentials, exported student workbooks, or result files.

Submission switches are disabled by default. Validate and review the workbook before enabling any update cell.
