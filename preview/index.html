    GP · General Profile
    • Mother Tongue: Hindi or Bhojpuri according to configured rule.
    • Blood Group: Under Investigation where eligible.
    • BPL, EWS, CWSN and Out-of-School-Child defaults are proposed only for eligible blanks.
    • Existing Yes values and other saved values are not overwritten; CWSN Yes requires manual review.
    EP · Enrollment Profile
    • Admission number uses matched eShikshaKosh value, then roll-number fallback.
    • Unmatched/ambiguous values are marked for review; temporary sequence is shown for Excel review only.
    • Language pair, subjects 3–6, previous-year result dependencies and Class XI stream follow configured rules.
    • GP prerequisite errors such as ER1010 are shown with the next action.
    FP · Facility Profile
    • Classes IX–X boys: 140–160 cm and 38–55 kg; girls: 135–155 cm and 34–50 kg.
    • Classes XI–XII boys: 150–170 cm and 42–60 kg; girls: 146–166 cm and 38–56 kg.
    • Facility Provided = No can propose No for blank/unanswered Olympiads, NCC, NSS and Scouts & Guides fields.
    • Existing Yes values are protected and flagged for manual review; blank facility Yes/No fields can be proposed as No.
    Complete Data · Finalize
    • Fresh completion status is read before action; only eligible status 3 records are proposed for submission.
    • One approved submission is followed by a fresh read-back to confirm status 6.
