1 · Session
1

Paste the cookie header

JSESSIONID + XSRF-TOKEN + NSC_tent load-balancer token, copied from the browser's Network tab. Verify with GET /p0/check-session.

Expires often. When it does, the API returns the SPA shell (HTML) instead of JSON, or a 200 with an INTERNAL_SERVER_ERROR body. Check for JSON before trusting any response. Auto-login is not implemented — the portal's login route has not been located.

Fetch the roster

GET /p0/api/cy/students/all/{schoolId} → 208 students with classId, studentId, PEN, roll no, and formStatus.

3

Load the eShikshaKosh OTR report

Supplies the Admission No. UDISE leaves blank, plus the Stream for Class XI. Either your export (--report file.xlsx) or a live fetch (--fetch-report, logs in with the school UDISE + password).

8

Cross-field rules — only where blank

The portal pairs these fields. A rule fires only on a field that is blank or already being written; a saved value is left alone.

4.1.15
BPL = No → AAY = Not Applicable (9). A student who is not BPL cannot be an AAY beneficiary.
4.1.16
Social category SC / ST / OBC → EWS = No (2). A reserved-category student cannot also claim EWS.
BLOOD
Code 0 ("Unknown") is offered by the UI but rejected by the API, so it is clamped to 9.

POST + read-back

POST /p0/api/cy/students/{sid} — 34 fields. Verified live: accepted, and every value preserved.

REQUIRED
The payload must carry the record's identity block — classId, sectionId, studentId, schoolId, gender, dob, parents' names, address, mobile, and the uuidUpdateYN / uuid / nameAsUuid trio.
A short payload omitting these returns INTERNAL_SERVER_ERROR even when the values are unchanged.
Verified live: 14 fields → INTERNAL_SERVER_ERROR · 34 fields → status: true, all values preserved.

14

Exam result valid? (1, 3, 4 only)

Field 4.2.7(a). Anything else cannot satisfy the requirement.

VALID
Write normally; previous-year values carried as saved.
INVALID
Auto rule → 4.2.5(a) = None / Not Studying
The portal then disables 4.2.6(b), 4.2.7(a)/(b), 4.2.8.
Transmit null for classPY, examResultPy, examMarksPy, attendancePy — sending 0/0/4/0 is rejected.
The portal stores sentinels 99 / 0 / 999 / 0; read-back must normalise them.

Cross-portal matching

Class and DOB are not hard filters — requiring them lost all 62 Class XI matches. One hard rule: Aadhaar last-4 on both sides and different = different person.
